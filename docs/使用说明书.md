## 一、开始之前:需要准备什么?

| 问题 | 答案 |
|---|---|
| 需要安装依赖吗? | **不需要**。项目零依赖,不用执行 `npm install` |
| 需要什么环境? | 只需要 **Node.js 14 或更高版本**(一次性安装;Windows 启动器可自动装) |
| 能直接双击网页用吗? | **不能**。浏览器安全机制不允许网页直接发 ping,必须先启动本项目的本地小服务(约 1 秒) |
| 会上传我的数据吗? | 不会。探测全部在本机完成,服务只监听本机(127.0.0.1),没有数据库、没有遥测 |

**检查是否已装 Node.js**:打开终端(Terminal / 命令提示符)输入 `node -v`,显示版本号(如 `v20.11.0`)即可。

**没有安装?** 三种方式任选:
1. **Windows 用户**:直接双击 `start.bat`,启动器会询问是否自动安装(见下节);
2. 打开 [https://nodejs.org/zh-cn/download](https://nodejs.org/zh-cn/download),下载 **LTS 版**,一路下一步安装;
3. macOS 用户也可用 Homebrew:`brew install node`。

## 二、启动(三步以内)

### 方式 A:双击启动(推荐给普通用户)

| 系统 | 操作 |
|---|---|
| macOS | 双击 `start.command` |
| Windows | 双击 `start.bat` |

启动器会自动运行服务,并在就绪后**自动调用系统默认浏览器打开页面**——全程无需复制任何网址。看到示波台界面即可开始使用。

> **Windows 用户注意**:
> - 启动器窗口显示**英文**是刻意设计:cmd 命令行对中文编码支持不稳定(中文批处理会出现乱码甚至报错),英文界面在任何 Windows 上都不会乱码;**网页界面仍然是中文**,功能完全一致;
> - **没装 Node.js?** 启动器会询问 `Install Node.js automatically now? [Y/N]`,输入 `Y` 会通过系统自带的 winget 自动安装(先直装 Node.js LTS,失败再走 fnm 方案);自动安装失败时会**自动打开官网下载页** [https://nodejs.org/zh-cn/download](https://nodejs.org/zh-cn/download),下载 LTS 版 `.msi` 安装(默认选项即可,会自动配置 PATH)后,再双击 `start.bat` 即可;
> - 若弹出 SmartScreen 蓝色提示:点「更多信息」→「仍要运行」。

> macOS 首次双击若提示"无法打开":右键 `start.command` →「打开」→ 再点「打开」;或在「系统设置 → 隐私与安全性」中允许。

### 方式 B:命令行启动(推荐给开发者)

```bash
cd netpulse
node server.js
```

然后浏览器访问 **http://127.0.0.1:8899**(端口被占用时会自动换下一个,以终端打印的地址为准)。

### 停止服务与释放端口

**正常情况(无需任何额外操作)**:关闭启动器窗口、或按 `Ctrl + C`,服务会**立即停止并释放端口**——程序已监听终端关闭信号,不会永久占用端口。之后网页会显示"本地服务未连接",重新启动即可。

**清理残留实例**(极端情况:强制退出终端、系统休眠恢复后怀疑端口仍被占),三种方式任选其一:

1. **双击清理器(最简单)**:双击项目里的 `stop.command`(macOS)或 `stop.bat`(Windows),自动停止所有 NetScope 实例并释放 8899–8918 端口;
2. **命令行一键清理**:在项目目录执行
   ```bash
   node server.js stop
   ```
   输出会列出停止了哪些实例(按 PID 精准清理,只动 NetScope 自己的进程);
3. **手动清理**(电脑上没有 Node.js 时):
   - macOS / Linux:先看占用再结束
     ```bash
     lsof -i :8899-8918        # 查看谁占用了端口
     lsof -ti :8899-8918 | xargs kill
     ```
   - Windows(管理员 PowerShell):
     ```powershell
     netstat -ano | findstr :8899
     taskkill /F /PID <上一步查到的 PID>
     ```

> 说明:程序把运行中实例登记在项目目录的 `.netscope.pids` 文件,`stop` 命令以此实现精准清理,进程退出时该登记会自动移除;文件已被 `.gitignore` 排除,不会提交到仓库。

## 三、基本操作

### 1. 测试一个目标

1. 在「目标」输入框填入 **IP 地址**(如 `1.1.1.1`)或**域名**(如 `example.com`);
   也可以点击下方的快捷按钮一键填入;
2. 选择探测方式(见下节);
3. 点击:
   - **单次测试** — 发 1 个探测包,快速看一眼;
   - **开始连续测试** — 按设定间隔持续发包,实时绘制波形;再点「停止」结束。

### 2. 两种探测方式怎么选?

| 方式 | 原理 | 什么时候用 |
|---|---|---|
| **ICMP 回显**(默认) | 调用系统 `ping`,测网络层真实往返延迟,还能看到 TTL(跳数) | 绝大多数情况;测服务器、路由、公网 IP |
| **TCP 握手** | 测量与目标某个端口建立 TCP 连接的耗时 | 目标**禁止 ping** 但有开放端口时(如网站 443/80、游戏服务器);很多服务器为防攻击禁用了 ICMP |

> 经验:ICMP 显示"超时/不可达"但你知道目标其实在线 → 切到 TCP 模式试试 443 或 80 端口。

### 3. 参数说明

| 参数 | 说明 | 建议值 |
|---|---|---|
| 间隔 | 连续测试时每次探测的时间间隔 | 常规 1s;抓抖动用 200–500ms;长时监测用 2–5s |
| 超时 | 单个包等待响应的最长时间 | 默认 2s;高延迟线路可加到 5s |
| 持续时长 | 连续测试到时**自动停止**并给出摘要 | 默认 1 分钟;可选 5/10/30 分钟或不限时 |

运行中,右上角状态灯会显示剩余时间(如「运行中 · 剩余 42s」),到时自动结束并弹出本次测试摘要(平均延迟、丢包率、评分)。

## 四、怎么看数据

### 波形图(主屏)

- **横轴** = 时间,最新的包在最右侧;**纵轴** = 延迟(毫秒),自动缩放;
- 琥珀色曲线(ICMP)或青色曲线(TCP)是每个包的往返延迟;
- 虚线是**平均值**;曲线下方的渐变填充帮助观察波动;
- 红色 **✕** 表示该包**丢失**(超时或不可达),曲线在此处断开。

### 右侧读数

| 指标 | 含义 | 怎么理解 |
|---|---|---|
| 当前延迟 | 最近一个成功包的往返时间 | 实时手感 |
| 平均 / 最小 / 最大 | 成功包的统计 | 最大值突然飙高 → 有瞬时抖动 |
| 抖动 jitter | 相邻两包延迟差的平均值 | 越小越稳;游戏/语音最在意这个 |
| P95 | 95% 的包都快于这个值 | 比"最大值"更能代表最差体验 |
| 丢包率 | 失败包占总包数的比例 | 理想为 0%;≥5% 明显影响体验 |

### 链路质量评分(0–100)

综合延迟、丢包、抖动自动打分:**≥85 优秀 / ≥70 良好 / ≥50 一般 / 低于 50 较差**。

**重要:评分是"距离感知"的。** 系统会识别目标 IP 的归属地(如"美国 · Ashburn"),计算与你本机的物理距离,按"这个距离的理论延迟"作为基准:
- 测美国 IP 得到 200–300ms → 属于跨洋线路正常水平,会标注「跨域线路正常水平:高延迟主要来自物理距离」,**不会**误判为线路差;
- 测同城/国内 IP 得到 200ms → 这才是真正的问题,会如实判差。

归属地信息显示在读数面板的目标下方(含国旗、距离、该距离的正常往返参考值)。

### 带宽测试

「带宽测试」面板可测你当前网络的**下载 / 上传带宽**:

- 点击「开始测速」,约 15–30 秒完成;流程:延迟探测 → 4 路并行下载 → 多路并行上传;
- 实时速率以大数字显示,右侧曲线图同步绘制(琥珀=下载,青色=上传);
- 结果显示下载 / 上传 Mbps 与平均延迟,可随时点「停止」中断;
- **注意**:测速会真实传输数据,约消耗 **60–100 MB 流量**,手机热点用户请留意;测速节点为 Cloudflare 边缘(自动就近);**开启代理/VPN 时,测得的是代理链路的带宽**,不代表本地运营商线路。

### 其他面板

- **延迟分布**:成功包延迟的分布直方图,P50(中位数)与 P95 已标注;
- **包序列日志**:每个包的明细(时间、延迟、TTL、状态),最新在最上;
- **本机网络环境**:你当前网络的全貌 —— **当前网络 IP**(本机在局域网中的地址,自动识别默认路由所用网卡;若默认路由走代理/VPN 隧道会如实标注)、出口 IP、运营商(ISP)、ASN、归属位置、时区、反向解析、出口类型(住宅/代理/数据中心),以及本机系统与内网网卡列表。可点「刷新」重查,「导出 JSON」保存。

### 导出数据

- **CSV**:全部包明细,可用 Excel / WPS 打开;
- **JSON**:完整会话(含统计汇总),适合程序处理;
- 文件名自动带上目标与时间戳。

## 五、隐私说明

- ICMP / TCP 探测**完全在本机进行**,不经过任何第三方服务器,测试结果只存在浏览器内存里;
- 「归属地识别」功能会把目标 IP 和你的出口 IP 交给免费公开服务 ip-api.com 查询大致位置(用于距离基准),**不涉及任何其他数据**;不放心可随时**关闭该开关**,页面会改用通用基准,此后完全离线;
- 带宽测试会连接 Cloudflare 测速节点(speed.cloudflare.com)传输真实数据;
- 服务默认只监听 `127.0.0.1`,局域网内其他设备无法访问你的测试页。

## 六、常见问题(FAQ)

**Q1:启动时提示"端口 8899 已被占用"?**
说明已有另一个 NetScope 实例在运行(比如之前的启动窗口没关)。服务会**自动改用下一个端口**(8900、8901…最多尝试 20 个)并在终端打印实际地址,浏览器自动打开的也是新地址,无需手动处理。想固定端口可用 `PORT=9100 node server.js`;想彻底关掉旧实例:双击 `stop.command` / `stop.bat`,或执行 `node server.js stop`(详见上文「停止服务与释放端口」)。

**Q2:为什么必须先启动服务?直接开网页不行吗?**
浏览器出于安全设计,禁止网页发送 ICMP ping、也禁止对任意 IP 计时。本项目用一个本地小服务(仅你的电脑可访问)代为执行真实探测,网页只负责展示。这是所有浏览器端网络测试工具的共同做法。

**Q3:提示"本地服务未连接"?**
服务没在运行。双击 `start.command` / `start.bat` 重新启动;如果端口改过,注意访问终端里打印的实际地址。

**Q4:所有目标都显示超时?**
① 检查本机网络能否上网;② 若在公司/校园网,ICMP 可能被网关拦截 → 换 TCP 模式试试;③ macOS/Linux 可在终端手动 `ping 1.1.1.1` 对照。

**Q5:测同一个网站,ICMP 和 TCP 差很多?**
正常。ICMP 走网络层、常被限速或降优先级;TCP 走真实建连路径。你开了代理/VPN 时两者路径也可能不同——NetScope 会如实显示两条路径的差异,这本身就是有价值的诊断信息。

**Q6:怎么在局域网其他设备(手机)上使用?**
启动时指定 `HOST=0.0.0.0 node server.js`,然后用手机访问 `http://你电脑的局域网IP:8899`。注意:此时局域网内任何人都可以借你的电脑发起探测,请自行评估(详见 README)。

**Q7:延迟数值和我在游戏里看到的不一样?**
统计口径不同(游戏多为内网到局服务器、且做了平滑),ICMP 也可能被运营商限速。关注**相对变化与丢包/抖动**比绝对值更有意义。

**Q8:数据会保存吗?刷新页面后没了?**
数据只在当前页面会话中。需要留存请点「CSV / JSON」导出。

**Q9:Windows 启动器窗口是英文/以前出现过乱码?**
启动器窗口使用英文是刻意设计:Windows 的 cmd 对中文批处理编码支持不稳定,中文可能乱码、甚至乱码碎片被当成命令执行导致连环报错。英文启动器在任何 Windows 上都不会乱码;网页界面仍是完整中文。旧版本(出现乱码的版本)请删除后使用最新版启动器。

## 七、技术速览(开发者)

```
netpulse/
├── server.js             零依赖 Node 服务:静态托管 + ICMP/TCP 探测 + 归属地 + 带宽测速 API
├── public/
│   └── index.html        单文件前端:示波器 UI、Canvas 图表、Three.js 背景、内置使用说明
├── start.command         macOS 双击启动器(启动后自动打开浏览器)
├── start.bat             Windows 双击启动器(未装 Node 时引导自动安装;ASCII 界面防乱码)
├── stop.command          macOS 一键停止全部实例并释放端口
├── stop.bat              Windows 一键停止
├── docs/使用说明书.md     本文档
├── .gitignore
├── package.json
├── LICENSE               MIT
└── README.md             项目说明(含 API 表)
```

环境变量:`PORT`(起始端口,默认 8899)、`HOST`(监听地址,默认 127.0.0.1)、`NETSCOPE_OPEN=1`(强制启动后自动开浏览器)、`NETSCOPE_NO_OPEN=1`(禁止自动开)。
