HELP 使用说明

快速上手

  • 在「目标」输入 IP 或域名(如 1.1.1.1),点「单次测试」快速看一眼,或「开始连续测试」持续监测;
  • 波形图实时绘制每个包的往返延迟,红色 ✕ 表示丢包(超时/不可达),虚线为平均值;
  • 「持续时长」默认 1 分钟,到时自动停止并弹出摘要;也可随时手动「停止」。

探测方式怎么选

  • ICMP 回显(默认):调用系统 ping,测真实网络层往返延迟与 TTL,适用于绝大多数目标;
  • TCP 握手:目标禁止 ping 但有开放端口时使用(网站填 443 或 80)。ICMP 全部超时而目标明明在线 → 换它试试。

评分是"距离感知"的

系统会识别目标归属地(目标下方那行,含国旗与距离),按该距离的正常延迟作为基准:

  • 测美国 IP 得到 200–300ms → 跨洋正常水平,不会被误判为线路差;
  • 测同城 IP 得到 200ms → 才会如实判「较差」。
抖动 = 相邻包延迟波动,越小越稳(游戏/语音最在意);P95 = 95% 的包都快于该值;丢包率理想为 0%。

带宽测试

  • 点「开始测速」约 15–30 秒,测下载/上传带宽与延迟,可中途停止;
  • 约消耗 60–100 MB 流量,手机热点用户请留意;开代理时测得的是代理链路带宽。

本机网络与导出

  • 「本机网络环境」面板展示你的出口 IP、运营商、ASN、位置与内网网卡,可刷新、可导出 JSON;
  • 测试数据可导出 CSV(Excel 可开)或 JSON(含统计汇总)。

隐私

  • ICMP / TCP 探测全部在本机执行,不经过任何第三方;
  • 「归属地识别」开关开启时,仅将目标 IP 与出口 IP 交由 ip-api.com 查询大致位置;关闭后完全离线(改用通用基准);
  • 服务只监听 127.0.0.1,局域网其他设备无法访问。

页面打不开了 / 服务未连接?

本页面需由本地服务提供:双击项目里的 start.command(macOS)或 start.bat(Windows),或运行 node server.js 后访问 http://127.0.0.1:8899。更详细的说明见项目内《docs/使用说明书.md》。
